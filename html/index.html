❐ Ayuda — Comandos soportados

Bases de datos

  • CREATE DATABASE compras; todos los SGBD
  • DROP DATABASE compras;
  • \l / \list — listar bases
  • \c compras / \connect compras — requiere CONNECT
  • BACKUP DATABASE compras; — dump simulado

Tablas y datos

  • CREATE TABLE cargos (id_car integer, car_descri character varying(100)); — requiere CREATE+USAGE
  • DROP TABLE cargos;
  • \dt — listar tablas • \d cargos — describir
  • INSERT INTO cargos (id_car, car_descri) VALUES (1, 'Gerente');
  • UPDATE cargos SET car_descri = 'Analista' WHERE id_car = 1;
  • DELETE FROM cargos WHERE id_car = 2;
  • SELECT * FROM cargos; — también SELECT car_descri FROM cargos;

Roles y usuarios

  • CREATE ROLE desarrolladores NOLOGIN; — rol de grupo
  • CREATE USER salmada WITH PASSWORD 'Clave123';
  • GRANT desarrolladores TO salmada; REVOKE desarrolladores FROM salmada;
  • \du — listar roles
  • SET ROLE salmada; / RESET ROLE;
  • DROP USER salmada; / DROP ROLE desarrolladores;

Permisos (validación 42501)

  • GRANT CONNECT ON DATABASE compras TO desarrolladores;
  • GRANT USAGE ON SCHEMA public TO desarrolladores;
  • GRANT CREATE ON SCHEMA public TO desarrolladores;
  • GRANT SELECT, INSERT ON ALL TABLES IN SCHEMA public TO desarrolladores;
  • GRANT UPDATE ON TABLE cargos TO soporte;
  • REVOKE SELECT ON ALL TABLES IN SCHEMA public FROM desarrolladores;

Sistema

  • SELECT version(); • SELECT * FROM pg_roles;
  • clear / cls — limpiar terminal
  • \q / quit / exit / salir — reiniciar

▷ Los privilegios se verifican de forma real: sin permiso se muestra ESTADO SQL: 42501 en rojo.

❐ Explicaciones — Roles, Usuarios y Permisos

En PostgreSQL todo se maneja con roles. Un usuario es un rol con la capacidad de iniciar sesión. Un rol de grupo (NOLOGIN) se usa para agrupar permisos y entregárselos a varios usuarios.

Flujo de prueba recomendado 
CREATE DATABASE compras;
\c compras
CREATE TABLE cargos (id_car integer, car_descri character varying(100));
INSERT INTO cargos (id_car, car_descri) VALUES (1, 'Gerente');
CREATE ROLE desarrolladores NOLOGIN;
CREATE USER salmada WITH PASSWORD 'Clave123';
GRANT USAGE ON SCHEMA public TO desarrolladores;
GRANT SELECT, INSERT ON ALL TABLES IN SCHEMA public TO desarrolladores;
GRANT CONNECT ON DATABASE compras TO desarrolladores;
GRANT desarrolladores TO salmada;
SET ROLE salmada;
SELECT * FROM cargos;          -- OK (SELECT + USAGE)
INSERT INTO cargos (id_car, car_descri) VALUES (2, 'Soporte');   -- OK (INSERT)
UPDATE cargos SET car_descri = 'X';   -- ERROR 42501 (sin UPDATE)
RESET ROLE;

Qué es cada comando

ComandoQué hace
CREATE ROLE x NOLOGIN;Crea un rol de grupo, no puede conectarse.
CREATE USER x WITH PASSWORD '...';Crea un rol con acceso (LOGIN) y contraseña.
GRANT rol TO usuario;El usuario hereda los privilegios del grupo.
SET ROLE x;La sesión actúa como el rol x (prueba permisos).
RESET ROLE;Vuelve al rol original (postgres).
GRANT USAGE ON SCHEMA ... TO x;Permite ver/recorrer el esquema.
GRANT CREATE ON SCHEMA ... TO x;Permite crear objetos (DDL) en el esquema.
GRANT SELECT, INSERT, ... ON ALL TABLES ... TO x;Entrega permisos de datos sobre las tablas.
GRANT CONNECT ON DATABASE ... TO x;Permite conectarse a una base de datos.
REVOKE ... FROM x;Retira privilegios o membresías.
