Base de datos

  • CREATE DATABASE compras; — solo superuser
  • \c compras / \connect compras — requiere CONNECT
  • \l / \list
  • BACKUP DATABASE compras; — dump simulado (RF-09)

Roles y usuarios

  • CREATE ROLE desarrolladores NOLOGIN;
  • CREATE USER salmada WITH PASSWORD 'Clave123';
  • GRANT desarrolladores TO salmada; / REVOKE desarrolladores FROM salmada;
  • SET ROLE salmada; / RESET ROLE; / \du

Permisos (validados 42501)

  • GRANT CONNECT ON DATABASE compras TO desarrolladores;
  • GRANT USAGE ON SCHEMA public TO desarrolladores;
  • GRANT CREATE ON SCHEMA public TO desarrolladores; — DDL
  • GRANT SELECT ON ALL TABLES IN SCHEMA public TO desarrolladores;
  • GRANT SELECT, INSERT ON ALL TABLES IN SCHEMA public TO soporte;
  • REVOKE SELECT ON ALL TABLES IN SCHEMA public FROM desarrolladores;

LMD / DDL (con UNIQUE/NOT NULL + ; obligatorio)

  • CREATE TABLE t (id INT PRIMARY KEY, email VARCHAR(100) UNIQUE NOT NULL); — requiere CREATE+USAGE, valida UNIQUE/NOT NULL
  • CREATE TABLE t2 (id INT NOT NULL, des VARCHAR(100)); — cierra siempre con ; si no, espera
  • ALTER TABLE t ADD COLUMN edad INT NOT NULL; / DROP COLUMN edad; / RENAME TO t2; / RENAME COLUMN a TO b;
  • \dt / \d cargos — requiere USAGE (muestra UNIQUE/NOT NULL)
  • SELECT * FROM cargos; — requiere SELECT
  • INSERT INTO cargos VALUES (3,'Analista'); — requiere INSERT, valida UNIQUE/NOT NULL
  • UPDATE cargos SET des='X' WHERE id=1; / DELETE FROM cargos WHERE id=2; — valida UNIQUE

Nota: Toda sentencia SQL debe cerrar con ;. Si das Enter sin ; se une con espacio y el prompt cambia a compras-# esperando el cierre, sin mensaje extra (como en AlmaLinux).
